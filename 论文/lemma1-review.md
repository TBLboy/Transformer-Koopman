### 2. 范数展开中没有明确使用 `U` 的正交列

## 已确认的正确内容

1. 由正交列结构，低秩修正的谱范数确实等于 `\max_j|\gamma_{\chi,j}(v)|`。
2. 由 softmax 分量属于 `[0,1]`、tanh 绝对值不超过 `1`，有 `|\gamma_{\chi,j}(v)|\le g_\chi`。
3. 由三角不等式，`\|A(v)\|_2\le\|A_0\|_2+g_A`，`\|B(v)\|_2\le\|B_0\|_2+g_B`。
4. softmax 雅可比的全局二范数上界 `1/2` 正确。
5. `L_\chi=g_\chi(\tfrac12\|W_\chi^\pi\|_2+\|W_\chi\|_2)` 与两条调度分支的 Lipschitz 界一致。
6. 该引理只给出矩阵有界性和对 context 的 Lipschitz 连续性，不推出 Schur 稳定性。正文中的这一限制说明是必要且正确的。

## 3.c 小节的理论路线

该小节的逻辑链可以概括为：

1. **建立模型误差来源。** 将由真实物理轨迹编码得到的 `\vz^E` 写成调度模型传播项加闭合残差 `\vr_i`。`\vr_i` 表示有限维 lifted 模型不能完全闭合真实动力学所产生的一步误差。
2. **建立调度矩阵的正则性。** 引理 1 由正交低秩结构、softmax 和 tanh 的性质，给出 `A(v)`、`B(v)` 的统一范数界及其对 context 的 Lipschitz 界。
3. **比较两条轨迹。** 对同一候选输入序列，比较真实轨迹编码得到的 `\vz^E` 与递归预测得到的 `\vz^P`。两者共享初始历史和输入历史，差异来自闭合残差以及历史误差导致的 context 差异。
4. **把历史误差反馈到当前误差。** 测量历史由过去 `P_h` 个读出组成，因此 context 误差由过去 lifted-state 误差组成。用 `\sqrt{P_h}` 将历史窗口误差压缩为统一上界。
5. **得到标量递推。** 得到
   `\|e_{i+1}\|\le\rho\,\|e_i\|+\varepsilon`
   形式的保守递推，其中 `\rho=a+b\sqrt{P_h}`。
6. **求解几何累积界。** 通过离散归纳得到
   `E_i=\varepsilon\sum_{j=0}^{i-1}\rho^j`，从而把一步闭合残差传播为有限预测时域内的多步误差界。
7. **解释结论边界。** 有限时域内不要求 `\rho<1`。只有当所有有界性和残差条件能够在任意长时域保持，并且 `\rho<1` 时，才可得到统一的长期上界。该结论仍然属于预测误差保证，不是闭环稳定性定理。

## 3.c 当前理论路线的潜在问题

- **`\rho` 是误差递推的充分上界，不是系统真实收缩率。** 即使 `\rho<1`，它表达的是所选范数和保守估计下的 sufficient condition，不能直接解释为实际时变 lifted dynamics 的谱收缩性质。
- **误差界依赖 operating-domain 假设。** 该理论只有在物理和递归预测历史都留在 `\mathcal H` 内时成立。误差界本身没有证明轨迹会留在该集合内。
- **闭合残差是外加的统一条件。** 有限训练误差或验证集最大误差不能自动推出 Assumption~`\ref{asm:residual}` 的 uniform bound。正文已经指出这一点，后续应保持该限定。
- **历史长度会直接放大保守系数。** `\sqrt{P_h}` 来自统一历史包络，不表示历史长度必然以该速度放大真实预测误差。
- **该小节证明的是预测器误差，不是闭环控制性能。** 它没有涉及控制器如何选取输入，也没有证明递归可行性、闭环稳定性或跟踪误差收敛。
- **定理名称和路线需要与后续控制分析保持区分。** 这里的 `E` 对比的是 encoded physical trajectory 与 recursive predictor。后续若分析 frozen MPC，还需要单独区分 closure/modeling error 与 scheduling-freezing error，不能把两者合并成同一个误差来源。

## 第四章 B 小节审查记录

审查对象：`Prediction Error Induced by Scheduling Freezing`，即 `main.tex` 第 1046--1192 行。

### 本小节的作用

第四章 B 小节要解决的问题是：递归调度预测器为了保持 QP 结构，先沿名义输入序列计算一组调度矩阵，再在优化候选序列时固定这组矩阵。候选输入序列与名义输入序列不同，所以真正递归更新 context 得到的预测 `\vz^P` 与冻结矩阵得到的预测 `\vz^F` 不同。

本小节只分析这一个新增误差来源。它不重新分析第 3.c 小节已经得到的闭合残差误差 `\vz^E-\vz^P`，而是建立

`候选输入与名义输入的距离`
`\longrightarrow` `递归状态、历史和 context 的偏差`
`\longrightarrow` `调度矩阵的偏差`
`\longrightarrow` `冻结预测误差`。

最后通过三角不等式把两种误差合并为

`\|\vz^E-\vz^F\|\le E_i+D_i\delta_k`。

因此，这一小节是连接“理论上的递归调度模型”和“实际用于求解 QP 的冻结 LTV 模型”的误差桥梁。

### 审查结论

增广系统的 Lipschitz 估计、冻结误差递推和总误差合成在当前假设下均成立，没有发现实质性数学错误。主要问题是部分常数的推导写得过快，冻结误差引理对名义轨迹的定义依赖前文，且若干结论边界需要更明确。

## 第四章 B 小节的理论路线

1. **明确实际 QP 与递归预测器的差异。** 递归预测器在每个预测步骤更新 context，因此矩阵序列依赖候选输入序列。QP 为了保持线性结构，使用名义输入序列生成矩阵并冻结它们。
2. **把递归预测器写成增广状态系统。** 将 lifted state、测量历史和过去输入历史合并为 `q=\col(z,X,v)`，使 context、状态更新和历史更新都成为同一个增广转移映射 `\mathcal F` 的组成部分。
3. **建立增广映射的 Lipschitz 界。** 引理 1 控制调度矩阵，context 编码器的 Lipschitz 条件控制 context，历史移位矩阵控制历史更新，最终得到 `q` 和当前输入变化对下一步增广状态的影响界。
4. **先估计候选递归轨迹与名义轨迹的差异。** 输入序列距离 `\delta_k=\|U_k-\bar U_k\|` 通过增广 Lipschitz 界传播为 `\|q_i^P-\bar q_i\|\le K_i\delta_k`。
5. **再估计冻结矩阵造成的 lifted-state 偏差。** 名义 context 与候选 context 的差异导致 `A`、`B` 的差异，进而得到 `\|z_i^P-z_i^F\|\le D_i\delta_k`。
6. **解释首步误差为零。** 初始历史相同，且当前输入不进入当前 context，因此第一个 lifted update 使用同一组调度矩阵。冻结误差从第二个预测步骤开始出现。
7. **与第 3.c 小节的建模误差合成。** `E_i` 表示闭合残差导致的误差，`D_i\delta_k` 表示调度冻结导致的误差，两者相加得到实际 QP 预测相对于编码物理轨迹的总预测误差界。

## 第四章 B 小节的潜在理论问题

- **冻结误差界是局部于共同正则域的。** 它需要候选递归轨迹和名义轨迹都留在 `\mathcal Q` 内，输入可行性本身不足以推出这一点。
- **误差与 `\delta_k` 成正比是条件性结论。** 该结论说明名义输入接近候选输入时冻结误差较小，但当前算法没有在优化问题中直接约束或最小化 `\delta_k`。
- **`D_i` 不代表闭环误差增长率。** 它是有限预测时域内冻结近似的敏感性上界，不能直接用于宣称闭环稳定或递归可行。
- **首步冻结误差为零不等于冻结策略整体无误差。** 后续预测步骤的矩阵差异仍会影响目标函数和最优第一控制输入。
- **总误差界分离了两种误差，但没有证明它们在实际数据上达到该上界。** `E_i` 依赖统一闭合残差假设，`D_i` 依赖共同域假设和保守 Lipschitz 常数。
- **本小节的开头对“practical closed-loop tracking”的承诺略超前。** 本小节本身建立的是冻结预测误差界。闭环跟踪条件应由后续 Closed-Loop Stability Analysis 小节给出，建议将开头句改成覆盖后续分析，或只描述本小节的预测误差目标。

## 第四章 C 小节审查记录

审查对象：`Closed-Loop Stability Analysis`，即 `main.tex` 第 1194--1599 行。

### 本小节的作用

第四章 C 小节把前两部分的预测误差界推进到闭环控制层面，目标不是证明 lifted predictor 本身稳定，而是证明在额外的物理系统条件下，冻结 QP 控制器具有 practical output tracking 性质。

其理论链条是：

`预测误差界`
`\longrightarrow` `理想目标与冻结目标的统一代价扰动界`
`\longrightarrow` `冻结 QP 最优输入与理想最优输入的偏差界`
`\longrightarrow` `真实系统有限时域 value function 的近似下降`
`\longrightarrow` `输出误差的有限时间界和 ultimate bound`。

具体而言，首先定义假想的 ideal objective `J_k^E`，它使用真实物理轨迹的未来输出，但不在线求解。然后利用第四章 B 小节的总预测误差界，得到 `J_k^E` 和实际冻结 QP 目标 `J_k^F` 之间的统一差异界 `\bar\Delta_N`。由于冻结 QP 的输入正则项正定，`J_k^F` 强凸，因此可以进一步控制两个最优输入序列之间的距离。最后引入真实系统的 value function 和 cost controllability 条件，建立带有建模误差、冻结误差及参考跟踪 allowance 的耗散不等式。

### 审查结论

目标扰动引理的数学推导成立，practical closed-loop tracking 定理中的代价递推、系数计算和最终输出界也成立。没有发现当前证明中的直接代数错误。该结论高度条件化，主要风险来自假设强度、假设可验证性和“闭环稳定性”这一标题可能造成的过度理解。

## 第四章 C 小节的理论路线

1. **构造理想基准。** 用真实物理系统产生的未来输出定义 `J_k^E`，把它作为冻结 QP 的理论基准。该问题只用于分析，不在线求解。
2. **建立目标扰动界。** 由第四章 B 小节的总预测误差界和冻结 lifted-state 界，得到每个预测步的输出误差上界 `\eta_i^{\max}`，再用加权平方差估计得到 `|J_k^E-J_k^F|\le\bar\Delta_N`。
3. **传递到最优输入。** 冻结目标由于 `R_u\succ0` 而强凸，因此冻结最优序列唯一。目标函数的统一扰动界给出冻结最优序列相对于理想最优序列的代价次优界和输入距离界。
4. **引入真实系统 value function。** 将当前输出代价 `p_k` 加回 MPC 目标，得到 `W_k=p_k+\min J_k^E`，从而可以用 value function 讨论闭环下降。
5. **加入 cost controllability。** 该假设把有限时域 value function 与当前 stage cost 联系起来，为 suffix cost 和尾部两步比较轨迹提供统一上界。
6. **处理冻结 QP 的次优性。** 实际控制器使用冻结最优序列。目标扰动界将其转化为相对于理想有限时域问题的 `\omega_N=2\bar\Delta_N` 次优性。
7. **构造下一时刻比较序列。** 保留当前最优序列的中间输入，并在末端接入真实系统的两步理想优化器，得到 `W_{k+1}` 的上界。
8. **得到带扰动下降。** 经过 suffix 递推得到
   `W_{k+1}\le(1-\lambda_N)W_k+d_N`。
9. **证明域内不变和输出 ultimate bound。** `d_N\le\lambda_NR` 保证 time-varying sublevel sets 前向不变，再由 `W_k\ge\lambda_{\min}(Q_x)\|x_k-x_k^r\|^2` 得到有限时间输出界和极限上界。

## 第四章 C 小节的潜在理论问题

- **最终定理是强假设下的条件性证书。** 它不能仅凭 Transformer--Koopman 模型结构、矩阵范数界或 QP 可行性推出。
- **cost controllability 和 closed-loop domain 是两个独立的外加条件。** 前者控制真实系统的代价可控性，后者保证误差估计和 value-function 递推能够持续适用。
- **结果针对输出 tracking。** 它没有证明未测物理状态、完整 lifted state 或任意内部状态的稳定性。
- **误差项 `\bar\Delta_N` 可能随 horizon 增长。** 因此加长预测时域同时改善 `\lambda_N` 和放大目标扰动，最终 bound 存在明确 trade-off。
- **理想最优策略不可在线获得。** `U_k^{E,*}` 只是分析基准，输入扰动界不能直接作为在线控制律的实现误差指标。
- **任意有界参考不保证零误差跟踪。** 非零参考维持输入的绝对惩罚、参考变化和 terminal completion 都可能进入 `d_{\rm cc}` 或 `\bar\Delta_N`。
- **若后续要把“stability”写进摘要或贡献，必须使用 practical output tracking、value-function decrease 或 ultimate boundedness 等准确表述，并附带完整假设条件。**

## 两个强假设的验证前置核对

### 已确认的数据事实

- 设备逻辑描述的是二维软体平台，四根绳索通过水平和竖直差动对驱动二维光点位置。
- 设备文档给出的默认采样周期约为 `0.2 s`，控制接口为二维输入。
- 处理后软体平台数据包含 `train.npz`、`val.npz` 和 `test.npz`，每个文件的字段为 `x`、`u`、`t` 和 `trajectory_id`。
- 数据共有 100 条轨迹，按 70/20/10 划分为训练、验证和测试集。每条轨迹 300 个采样点。
- 各轨迹采样间隔约为 `0.2 s`。
- 状态 `x` 是二维观测，输入 `u` 是二维量。数据范围约为
  `x\in[-10.46,11.10]\times[-10.30,10.89]`，
  `u\in[-68.51,57.20]\times[-65.29,61.60]`，具体极值跨越三个数据划分。
- 旧工程按训练集统计量归一化 `x` 和 `u`，验证集和测试集复用训练集统计量。该数据接口与当前验证所需的轨迹边界处理一致。

### 当前验证能力

- 可以用真实采集轨迹估计经验运行域 `\mathcal O`、输入范围、采样周期、轨迹边界和数据覆盖情况。
- 可以在独立的验证轨迹上检查候选比较轨迹的代价关系，形成 cost controllability 的有限样本证据。
- 可以用真实轨迹和独立的动力学代理模型检查 `W_k` 子水平集是否在给定输入集合和参考轨迹族下保持在指定运行域内，形成 closed-loop domain 的代理证据。
- 这些结果可以支持“在数据覆盖的有限运行域和参考轨迹族上观察到该性质”，不能单独证明理论假设对所有状态、所有输入和任意长时间成立。

### 已解决的输入语义口径

原始系统中 `u` 表示每个采样周期的步进电机脉冲数量。数据中的浮点值来自理论连续控制量到工程执行量的处理过程。论文理论层面继续将 `u` 建模为连续输入，设备执行时再通过脉冲量化实现。步进分辨率足够高时，该量化误差属于工程实现误差，不改变当前理论主线。

验证时应在连续输入空间中定义 `\mathcal U` 和 stage cost `\ell_t`，同时把脉冲量化作为实现侧的输入约束和误差来源单独记录。原始数据的浮点形式不再视为理论验证阻塞。

### 推荐的验证顺序

1. 在连续理论输入空间中定义 `\mathcal U`，并记录脉冲量化作为实现侧约束。
2. 根据确认后的输入口径定义状态运行域 `\mathcal O`、参考轨迹族和代价权重。
3. 用训练集建立统计量，用验证集和测试集做轨迹级验证，避免把同一条轨迹的相邻样本当作独立证据。
4. 先检验 cost controllability 的有限样本不等式，再检验 closed-loop domain 的子水平集保持性。
5. 最后计算 `\lambda_N` 和 `d_N`，检查理论 tracking certificate 是否满足
   `\lambda_N>0` 和 `d_N\le\lambda_NR`。
