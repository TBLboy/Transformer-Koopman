## 1. 被控对象（done_when#1）

**标准 cart-pole（倒立摆装在可平动小车上）**，杆角 `theta` 自竖直向上量起。

| 量 | 值 |
|---|---|
| 状态 | `x = [p, p_dot, theta, theta_dot]` |
| 输入 | `u` = 作用在小车上的力 [N] |
| 参数 | M = 1.00 kg, m = 0.10 kg, l = 0.50 m, g = 9.81 |
| 积分 | RK4，dt = 0.020 s（与离散模型同步） |

动力学（对 `[p_ddot, theta_ddot]` 解 2x2 线性系统，`theta = ±pi/2` 附近也无奇点）：

```
[ (M+m)      m*l*cos(t) ] [ p_ddot ]   [ u + m*l*t_dot^2*sin(t) ]
[  cos(t)     l         ] [ t_ddot ] = [ g*sin(t)               ]
```

## 2. 输入耦合**确实依赖状态**（本文 B(chi) 的物理动机）

`d f / d u` 在若干杆角处的数值线性化（第 2、4 通道 = `p_ddot` 与 `theta_ddot` 对 u 的敏感度）：

| theta | [d p_ddot / d u, d theta_ddot / d u] |
|---|---|
| 0.00 | [0.020003, -0.040058] |
| 0.10 | [0.019983, -0.039817] |
| 0.20 | [0.019924, -0.039103] |
| 0.30 | [0.019829, -0.037933] |
| 0.45 | [0.019630, -0.035392] |
| 0.60 | [0.019383, -0.032028] |

**最大相对变化 20.05%**：同一个力在不同杆角下对加速度的作用不同。
这是本文把输入矩阵写成 `B(chi_k)`（依赖当前**测量**）而非常数 `B_0` 的物理理由。
**注意**：这是本对象的性质，**不是**「文献中有 B(chi) 直接对应物」的证据（见 `09` §2.3 与 `10` §1 边界框）。

## 3. 灰箱 scheduled 代理（本文模型形式的一个实例）

`A(c) = A_0 + U_A diag(gamma_A(c)) V_A^T`，`B(chi)` 同理；本例 `n_psi = 0`（`d = 4`）、
`r_A = r_B = 2`、`gamma` 取**奇、偶两个通道**（`tanh(c)` 与 `tanh(|c|)`）。
**实测与纸面核对**：在工作点 `[0,0,theta,0]` 处，cart-pole 的线性化 `A(theta)`、`B(theta)` 的**全部元素都是 theta 的偶函数**
（关于 `theta = 0` 对称，json 中逐点目标范数也严格对称），因此 `tanh(c)` 这个**奇通道恒为 0**——
即下表 `g_A`/`g_B` 的第一个分量恰为 0，是**死通道**；真正起作用的是偶通道 `tanh(|c|)`。
也就是说 `r = 2` 在本例中等价于「**偶通道 rank-1**」；这是本实例的受限项之一（见 §5）。
`U/V` 的列已归一化（见下表），幅度写在 `gamma` 的系数 `g_k` 里。**softmax 混合本例未使用**（已登记）。

拟合数据：cart-pole 在 9 个工作点（`theta` 均匀取自 [-0.6, 0.6]，其余状态为 0）的线性化，交替最小二乘。

| 量 | 值 |
|---|---|
| 通道系数 g_A | 0.000000, 0.120374 |
| 通道系数 g_B | 0.000000, 0.012209 |
| ‖U_A 列‖ / ‖V_A 列‖ | 1.000000, 1.000000 / 1.000000, 1.000000 |
| ‖U_B 列‖ | 1.000000, 1.000000 |
| 拟合相对残差（A，Frobenius） | 2.784e-01 |
| 拟合相对残差（B，Frobenius） | 2.586e-01 |
| 逐点谱范数相对残差（A，最大） | 2.422e+00 |
| 逐点谱范数相对残差（B，最大） | 2.360e+00 |

> 两种残差都要看：Frobenius 是**整体拟合质量**，逐点谱范数可能**大于** 1 —— 这表示在某些工作点上，
> 未捕获的残差超过了修正本身的幅度（逐点谱范数残差可以超过该点自身的修正范数）。
> 这不影响模型自身自洽（命题 1 按定义成立），但它**就是**第 3 节下半部分那层模型失配的来源。
| 命题 1：max‖A(c)-A_0‖₂ = 0.086224 = g_A | 成立（按定义取等号） |
| 命题 1：max‖B(chi)-B_0‖₂ = 0.006557 = g_B | 成立（按定义取等号） |

**模型失配（必须如实看）**——代理模型与真 plant 的线性化之间的残差：

| 量 | 绝对值（谱范数） | 相对值 |
|---|---|---|
| ‖A_model - A_plant‖₂（工作点最大） | 0.0226 | 1.81% |
| ‖B_model - B_plant‖₂（工作点最大） | 0.0015 | 3.34% |

一步预测（`theta = 0.30` 附近、零输入）模型 vs plant：**1.215e-02**。
→ 本文的理论结论针对**模型**；用到真 plant 上会叠加这层失配，本轮**不**对失配下的闭环行为作任何声称。

## 4. 闭环对比（done_when#2）：完整 scheduled MPC vs 冻结 LTV-MPC，**都在真 plant 上**

设置：时域 N = 20、闭环 60 步、初始杆角 0.30 rad、限幅 ±20 N、`Q = diag(1, 0.1, 20, 1)`、`R = 0.05`；
终端代价 `P` 取该线性化的**离散 Riccati 解**（LQR），名义 rollout 由 LQR 增益驱动——
因为倒立摆的线性化本身不稳定（不稳定特征值 ±sqrt((M+m)g/(M l)) ≈ ±4.65），零输入的名义 rollout 会指数发散、使调度序列失去意义。
两个控制器**只有一处不同**：完整版每步用名义 rollout 重算调度序列；冻结版把调度冻结在当前测量。两者用同一代理模型，施加的 u 作用在**真 plant** 上。

| 指标 | 完整 scheduled MPC | 冻结 LTV-MPC |
|---|---|---|
| 闭环代价 | 83.1444 | 83.1053 |
| 末端状态范数 ‖x_N‖ | 5.275e-01 | 5.238e-01 |
| 末端杆角 theta [rad] | -5.130e-02 | -5.089e-02 |
| 末端小车位移 p [m] | 4.672e-01 | 4.632e-01 |
| 平均 |u| [N] | 1.949 | 1.956 |
| 单步求解耗时中位数 [ms] | 2.21 | 1.90 |

**代价相对差（冻结 − 完整）/|完整| = -0.0471%**。
**同一输入序列下两个模型 rollout 的最大偏差 = 1.594e-01**（模型层面的量，确认冻结确实改变了预测）。

**如实报告的两点观察（不要读成结论）**：

1. 这个实例里两个控制器的代价差**极小**（-0.0471%），且**冻结版略低**——本文件**不**作「完整版更优」的暗示，
   也不作反向暗示。可能原因：该实例的调度调制本身较弱（`g_A` = 0.086224，而 `‖A_0‖` 量级为 1），
   闭环里模型失配与 QP 求解精度的影响与之相当。
2. 两个控制器的末端小车位移都约 0.46 m（未回到 0）——杆被稳住了（末端杆角约 -0.05 rad），但小车漂移；
   这是有限时域 + 小车位置权重较小的正常结果，不是发散。

## 5. 诚实边界（必读）

- **临时验证**，结果**不进论文**（REQ-002 / BA-003）。
- **不作实时性声称**：耗时只是观察；L-BFGS-B 不是 MPC 求解器；两个控制器计算量本就不同。
- **不作闭环稳定性 / 递归可行性声称**：无终端**约束**（只有终端代价）、无可行性论证，只是有限步仿真。
- **不作「理论已被 plant 验证」的声称**：理论针对模型；plant 引入了第 3 节的模型失配。
- **不作「B(chi) 有文献直接对应物」的声称**：第 2 节展示的是本对象的物理性质。
- 本例是模型形式的**受限实例**：`n_psi = 0`、`r = 2`、`gamma` 用两个固定通道、**未使用 softmax 混合**、
  `c` 与 `chi` 都取自杆角（`chi` 只取当前测量）、`U_k^in` 未进入 context、历史窗口 `P = 2` 很短、拟合是**线性化灰箱**而非数据驱动辨识。
- 命题 1 的两行「取等号」是因为 `g_A`/`g_B` 按 `max‖A(c)-A_0‖` 定义；这**只**说明界按定义成立，不含紧性信息。
